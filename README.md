# Badminton Cost Calculator

羽毛球活动盈亏计算器：输入场地、用球、人数和收费，实时查看收入、成本、净利润及保本均价。

## 项目概况

单文件静态页面，无外部依赖，支持桌面和手机浏览，无需安装或构建。

## 文件说明

| 文件 | 用途 |

| README.md | 使用与维护说明 |

## 使用方式

直接打开 index.html，或访问 https://mayue-labs.github.io/badminton-cost-calculator/ 。修改任意输入，账单自动更新。输入数据仅在当前页面内计算，并自动保存在当前浏览器的本地存储中，刷新或重新打开后自动恢复。不同浏览器、设备之间不互通；清除网站数据后恢复默认值。浏览器禁止存储时仍可正常计算，但无法保存。

## 交互规则

- 修改输入后，实时显示收入、成本、盈亏和保本提示。
- 场地费 = 单价 × 片数 × 时长；总成本 = 场地费 + 用球 + 其他费用。
- 总收入 = 男生人数 × 男生收费 + 女生人数 × 女生收费；净利润 = 总收入 − 总成本。
- 保本均价 = 总成本 ÷ 总人数；人数为零时显示无收入提示。
- 输入项由 ids 数组关联，input 事件触发 calc() 和 saveInputs()，启动时 restoreInputs() 恢复数据；num() 读取数值，fmt() 格式化金额。

## 修改与维护

样式在 style 中，默认输入在对应 input 元素，计算规则在 calc() 中。修改后同步更新本文档及 CHANGELOG.md，检查默认账单和手机布局，再提交到 main。GitHub Pages 使用 main 分支根目录的 index.html。文件名遵循静态首页约定，中文 title 与 H1 保持一致。
